# Hướng dẫn thay thế ảnh mẫu trên trang Cộng đồng

Để thay đổi các ảnh mẫu trên trang cộng đồng bằng ảnh từ máy tính của bạn, hãy lưu các file ảnh của bạn vào thư mục `images` này và đặt đúng tên tương ứng như sau:

## 1. Tác phẩm của Hải Đăng (Card 1)
*   **Ảnh gốc (chưa xử lý)**: đặt tên là `card1_orig.jpg`
*   **Ảnh đã xử lý (đã tách nền)**: đặt tên là `card1_proc.png`

*Lưu ý:*

- Nếu ảnh của bạn có định dạng khác (ví dụ `.png` cho cả hai), hãy chuyển đổi chúng hoặc cập nhật phần đuôi mở rộng tương ứng trong tệp `community.html`.
